🤖 Réglages IA (Google Gemini)

Générez des blind tests sur-mesure ultra-rapides (< 1s) pour vos thèmes personnalisés en connectant Google Gemini gratuitement.

💡 Comment obtenir votre clé gratuite ?
  1. Allez sur Google AI Studio
  2. Connectez-vous avec votre compte Google et cliquez sur "Create API Key"
  3. Copiez votre clé et collez-la ci-dessus !

🔒 Sécurité : votre clé reste stockée localement dans votre navigateur (localStorage). Elle n'est jamais envoyée sur Git ni visible par quiconque.

⚙️ Option : URL Proxy Cloudflare Worker

Optionnel. Si vous déployez le script dans le dossier tools/cloudflare-worker.js.

📖 Comment jouer ?

🎯 Solo QCM : Répondez le plus vite possible pour accumuler un bonus de rapidité et des multiplicateurs de série !

🚨 Soirée Buzzer : Posez le smartphone ou la tablette au centre de la table. Chaque joueur a son coin d'écran. Le premier qui touche gagne 5 secondes pour crier sa réponse !

📲 Comment installer l'application ?

🤖 Android (Chrome) : Une invite apparaît souvent automatiquement au bas de l'écran. Sinon, touchez les 3 points verticaux en haut à droite > "Installer l'application" (ou "Ajouter à l'écran d'accueil").

🍏 iPhone (Safari) : Ouvrez le jeu dans Safari, appuyez sur le bouton Partager (le carré avec la flèche vers le haut 📤 en bas), faites défiler et choisissez "Sur l'écran d'accueil".
